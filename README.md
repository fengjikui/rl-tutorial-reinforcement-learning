# 强化学习和多模态教程 · 拆分版（第一部分：强化学习）

把一本 358 页的《强化学习和多模态教程》（作者：左元）拆成两部分，这个仓库只放前半部分，也就是第 1–10 章的强化学习内容。

原始 `main.pdf` 是一本合订本，前半讲强化学习（策略梯度 → PPO → GRPO → 用 PPO/GRPO 微调大模型），后半讲多模态（ViT → CLIP → ClipCap → 扩散模型 → DALL·E2）。

## 切点为什么在 p182

- p183 是分部页「多模态 Ⅲ」，p184 是第三部分的目录，p185 才是「11. Vision Transformer」正文。
- 所以 p1–p182 正好覆盖完整的第 1–10 章，不带半章、也不带后半的目录页。
- 182 与常说的「前 181 页」差一页，是第 10 章最后一页的版面页（含页眉页脚，无正文）。

## 做了什么处理

1. 按页原样复制，没有重排、压缩图片或改字体；只做了 deflate 与垃圾对象清理，体积从原始合订本相应页段略降。
2. **重建了书签**：分割后的 PDF 保留落在本段内的章节条目（本文件 96 条），页码已平移到段内页码，打开即可按章节跳转。
3. 写入了元数据（标题、作者、来源说明）。

## 怎么复现

```bash
python3 -m pip install pymupdf
python3 split_pdf.py main.pdf --outdir out
```

脚本默认切点在 p182，`--cut` 可改。切点依据是 PDF 自带的书签（`doc.get_toc()`）与分部页位置，不依赖人工数页。
